# Favorit Parts — поиск запчастей

Тестовое задание: двухэтапный поиск производителей и аналогов через API Favorit Parts.

**Стек:** React · Redux Toolkit · Bootstrap 5 · Bootstrap Icons · Vite · Vitest

## Запуск

```bash
npm install
npm run dev
```

Откройте `http://127.0.0.1:5173`.

```bash
npm test      # тесты
npm run build # production-сборка
```

## Как работает

1. **Этап 1.** Ввод артикула → `GET /hs/hsprice/?key=…&number=…` → список брендов.
2. **Этап 2.** Выбор бренда → тот же endpoint с `brand` и `analogues=on` → таблица предложений и аналогов (название, производитель, цена, остаток).

В разработке запросы идут через Vite-прокси (`/api` → `api.favorit-parts.ru`), чтобы обойти CORS.

Примеры артикулов: `01089`, `7160500039S`.

## Что покрыто тестами и зачем

| Что | Зачем |
| --- | --- |
| Нормализация ответа API (пустой `goods`, слэш в бренде, flatten аналогов) | Логика критична для корректного UI; падения API не должны «ломать» экран |
| Redux: данные таблицы не сбрасываются при повторной загрузке | Убирает «моргание» при смене бренда |
| Форма: кнопка неактивна без артикула | Базовый UX-контракт поиска |

## Структура

```
src/
  api/           # клиент Favorit API + unit-тесты
  components/    # UI: поиск, бренды, таблица/карточки, empty state
  store/         # Redux Toolkit slice + тесты состояний
```
